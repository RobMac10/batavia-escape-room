# In Case of Emergency

An escape-room story of the Batavia, for Year 4.

Open `index.html` in a browser, or serve the folder (for example `python3 -m http.server`) and visit the local address. There is no build step.

Progress is saved in this browser with localStorage. Use **Start the night again** in the menu to clear it.

This folder is a draft. It is not a published site.
